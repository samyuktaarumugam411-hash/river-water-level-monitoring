# river-water-level-monitoring
An IoT-based River Water Level Monitoring and Flood Warning System using ESP8266, sensors, GSM communication, and cloud-based monitoring to track river conditions and provide early alerts during potential flood situations.
# River Water Level Monitoring System

## Project Overview
An IoT-based River Water Level Monitoring System designed to monitor river conditions and transmit sensor data remotely using cellular communication and MQTT.

## Hardware Components
- ESP8266
- Water level sensor
- Turbidity sensor
- GPS module
- GSM module
- Other supporting sensors and components

## Features
- River water level monitoring
- Sensor data collection
- GPS-based location tracking
- GSM-based cellular data transmission
- MQTT-based data publishing to a broker
- Remote monitoring of river conditions

## Technologies Used
- Visual Studio Code
- Embedded C/C++
- ESP8266
- MQTT protocol
- GSM cellular communication
- Arduino framework and libraries, if used

## Working Principle
The sensors collect river condition data, which is processed by the controller. The GSM module provides cellular connectivity to transmit the data to an MQTT broker. An MQTT client or subscriber can then receive the published data for remote monitoring and further processing.

## Project Objective
The objective is to develop a remote river monitoring system that collects sensor data and makes it available through an MQTT-based communication system.
